# General information

Data from the GEMS/Water Global Freshwater Quality Archive (GEMS) (water quality observations, monitoring station latitude and longitude) included in Caravan-Qual was retrieved from the United Nations Environment Programme. Caravan-Qual only contains data that is available under the GEMStat OPEN data policy (equivalent to Creative Commons license CC BY 4.0) which allows data utilization for all purposes. 

Please note that there is additional data retrievable from GEMS, but this is under a LIMITED data policy (equivalent to Creative Commons license CC BY-NC 4.0). Therefore, these data are not included directly in Caravan-Qual. However, this data is still available on request via email to gwdc@bafg.de (for larger data requests of more than 600 stations).

version 3 of this dataset is currently included (10.5281/zenodo.18459694)
