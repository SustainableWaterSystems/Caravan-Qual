# General information

Data from the EMPODAT NORMAN (EMPODAT) (water quality observations, monitoring station latitude and longitude) included in Caravan-Qual was retrieved from the NORMAN network API (https://www.norman-network.com/nds/api/). It represents an aggregated database with heterogeneous licensing.
