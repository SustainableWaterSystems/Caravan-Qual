# README

## Requirements

- [Anaconda](https://www.anaconda.com/download) or [Miniconda](https://docs.conda.io/en/latest/miniconda.html)

## Setting up the environment

Create and activate the conda environment from the provided `environment.yml`:

```bash
conda env create -f environment.yml
conda activate explore_caravan-qual
```

This will install all required dependencies (Python 3.11, xarray, pandas, numpy, matplotlib, cartopy, and Jupyter) via conda-forge.
